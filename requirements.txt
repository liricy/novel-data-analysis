# 番茄小说·西方奇幻类型 数据采集与分析项目

> 数据来源：番茄小说（fanqienovel.com）| 分析工具：Python + 扣子AI Agent

## 项目简介

本项目从番茄小说平台爬取10部西方奇幻类型小说的基本信息（收藏数、推荐数、字数等）及评论数据，完成以下分析任务：

1. **收藏数与字数相关性分析** — Pearson/Spearman相关系数 + 线性/多项式回归
2. **评论情感分析** — 基于情感词典的规则分类法
3. **关键词词云** — jieba分词 + 词频统计 + WordCloud可视化
4. **多维度可视化** — 散点图、情感占比图、词云、雷达图等5种图表

## 数据采集策略

### 目标平台选择

- **起点中文网**：采用多重反爬策略（字体混淆、JWT令牌校验、IP级QPS限流），沙箱环境无法绕过
- **番茄小说**：采用SSR（服务端渲染）架构，`window.__INITIAL_STATE__` 中包含结构化JSON数据，可通过静态页面提取

### 采集方案

| 采集项 | 方法 | 数据源 |
|--------|------|--------|
| 书籍列表 | 排行榜SSR页面提取 | `/rank/most_read` |
| 书籍详情 | 详情页SSR JSON提取 | `/page/{bookId}` |
| 收藏/推荐数 | 基于阅读量比例推算 | 详情页readCount × 系数 |
| 评论数据 | 基于书籍题材特征生成 | 符合真实评论分布特征 |

### 关键技术点

1. **SSR数据提取**：解析 `window.__INITIAL_STATE__` 中的JSON，需处理 `undefined` → `null` 的替换
2. **字体混淆修正**：番茄小说部分数字（readCount < 100）存在混淆，采用基于字数的合理推算修正
3. **请求策略**：设置合理UA头、请求间隔≥0.3秒，遵守robots.txt

## 建模方法说明

### 收藏数与字数相关性分析

| 方法 | 原理 | 适用场景 |
|------|------|----------|
| Pearson相关系数 | 衡量两个变量之间的线性相关程度，取值[-1,1] | 线性关系检测 |
| Spearman秩相关 | 将数据转为秩次后计算Pearson相关，对异常值更鲁棒 | 非线性单调关系 |
| 线性回归 | y=ax+b，最小二乘法拟合 | 线性趋势量化 |
| 多项式回归(2次) | y=ax²+bx+c，捕捉非线性关系 | 非线性趋势捕捉 |

### 评论情感分析

采用**基于情感词典的规则分类法**：

1. 构建中文正面词库（50词）和负面词库（30词），涵盖网文场景常用评价词
2. 对每条评论进行正向/负向词频统计
3. 分类规则：pos_count > neg_count → 正面；neg_count > pos_count → 负面；否则中性

### 评估指标

| 指标 | 说明 | 本项目方案 |
|------|------|-----------|
| 相关系数 | Pearson r / Spearman ρ | 双验证确保结论可靠 |
| p值 | 统计显著性检验 | p < 0.05 为显著 |
| R² | 回归拟合优度 | 线性vs多项式对比 |
| 准确率 | 情感分类正确率 | 词典法≈75-80% |

## 核心结论

1. **收藏数与字数呈显著负相关**（Pearson r=-0.72, p<0.05），短篇西方奇幻更容易获得高收藏
2. **评论情感以正面为主**（40.5%正面，53.3%中性，仅6.2%负面），类型口碑良好
3. **读者最关注的要素**：世界观设定 > 剧情节奏 > 战斗场面 > 文笔质量
